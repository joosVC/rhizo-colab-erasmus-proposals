# Ideal consortium and indicative partner envelopes

## Design the functions before recruitment

RHIZO usually proposes the applicant school as the practice anchor: contextual knowledge, co-design, feasibility testing and pedagogical transfer. This is an internal default, not an EU requirement that a school must always coordinate.

| Function | Contribution and reason to join |
| --- | --- |
| School practice anchor / core knowledge partner | Ground the need, contribute school expertise, test feasibility and embed the approach |
| Topic/practical expert | Contribute an established or promising method and learn how to adapt it to formal education |
| Science/evaluation expert | Deepen the framework and identify credible, feasible ways to assess change |
| Network/uptake partner | Reach appropriate users and support adoption, professional learning and continued use |
| Implementation partners | Contribute contextual feedback and apply/test the approach in other schools/countries |

These are functions, not compulsory separate institutions. One organisation can combine topic and evaluation expertise, or school and network functions. Add specialised ethics, media or pedagogical expertise only where the mechanism needs it. Count core organisations, not the number of expertise labels, when sizing lead results and budget slots.

Distinguish core knowledge partners from implementation partners by tasks, not prestige or institution type. Core partners can pilot too. Implementation partners normally have smaller, task-based envelopes. Describe the mutual gain for each proposed profile and missing evidence of capability. Do not invent named organisations, countries, commitments or confirmed recruitment outcomes.

A capable network partner is RHIZO's default requirement from a €250,000 KA220 upwards, a case-dependent choice at €120,000, and not normally necessary as a separate partner at €60,000. State this as RHIZO's scale/uptake choice, never as an EU eligibility rule. Allow a genuinely capable existing core organisation to cover the function if justified.

## Slot heuristic — an initial design aid

Use only when an amount is supplied or explicitly proposed. Explain the assumptions. Let K be core knowledge organisations, B the requested grant and one extra slot an optional pooled implementation envelope:

**With a pool: indicative core envelope = B / (K + 1); implementation pool = B / (K + 1).**

Split the pool between actual implementation partners according to tasks. Without a separate pool, start with B / K. These are provisional allocations of the requested grant, not estimates of total project cost, prescribed EU rates or a detailed WP budget. Check any co-financing requirements separately.

| RHIZO scale | Typical starting sketch |
| --- | --- |
| KA210 €60,000 | Usually 2–3 core partners; €30,000 each for two or €20,000 each for three if tasks support that split. No automatic extra pool. |
| KA220 €120,000 | Example: 3 core + 1 pooled slot = €30,000/core and €30,000 pool, perhaps three implementation schools at €10,000 each. |
| KA220 €250,000 | Usually 5 or 6 total slots: 4 or 5 core organisations plus 1 pool; €50,000 or about €41,667 per slot. Reconcile rounding exactly if quoting totals. |
| KA220 €400,000 | Normally at least 6 slots including one pool; justify a wider implementation base and adequate support rather than simply inflating outputs. |

RHIZO normally designs KA210 at €60,000. Do not substitute €30,000 unless explicitly requested. €5,000–€10,000 per implementation school can be a useful starting range, not a guaranteed entitlement; the number of schools follows tasks and feasible support. Do not divide a €50,000 pool among three schools and silently leave €20,000 unallocated.

Start roughly equivalent for comparable core workloads, then adjust for actual responsibilities and accountability. A core lead's envelope includes its management contribution and other tasks; do not add WP1 on top and exceed B. Partner envelopes and WP budgets are different views of the same grant and must reconcile later.

Show actual organisation count separately from slot count: 4 core organisations plus a pool covering 5 formal schools means 9 prospective formal partners, not 5. Country eligibility/minima concern formal partners, not slots. National coverage and transferability matter, but do not invent countries to claim eligibility is satisfied.

Other local participating schools can sometimes be supported through a formal partner's activities. Distinguish them from funded formal partners and unfunded associated partners. Do not automatically model onward cash grants to schools as permitted, call them funded associated partners, or count them towards consortium minima. Flag that exceptional arrangement for a specific eligibility/contract check; use the standard formal implementation-partner model unless an alternative is justified.
