# Call-year source registers

These registers provide versioned locators for Erasmus+ policy screenings, separate from reusable skill instructions. They contain source identity and verification coverage, not a full document archive or confidential project reports.

The [2026 register](2026/manifest.json) includes the Guide, original Erasmus+ Annual Work Programme and the April amendment with its replacement annex. Official metadata and selected relevant sections were inspected on the stated check date, not the full corpus. Use the replacement annex for operative AWP conclusions and recheck later changes. Null checksums indicate that source bytes were not archived here.

For a new call year, add a new directory, verify the actual official documents and record relevant changes. Preserve older registers. Follow the [version protocol](../.agents/skills/erasmus-policy-scan/references/version-updates.md). A register check date is not a substitute for checking current versions during a live run.
